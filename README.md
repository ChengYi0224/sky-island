# Sky Island 空島

使用 Three.js 製作的 32×32×32 空島靜態網頁遊戲。

## 指令說明

- 執行單元測試：
  ```bash
  npm test
  ```
- 打包靜態網頁腳本（產生 `dist/bundle.js`）：
  ```bash
  npm run build
  ```

## 如何遊玩

1. 直接在檔案總管雙擊 `index.html` 用瀏覽器開啟（無需啟動伺服器）。
2. 點擊畫面中央鎖定滑鼠游標，進入第一人稱視角。
3. 操作方式：
   - **移動滑鼠**：自由旋轉第一人稱視角
   - **W / A / S / D**：前後左右水平移動
   - **Space（空白鍵）**：向上跳躍
   - **Esc**：解除滑鼠鎖定
