# Sky Island 空島

使用 Three.js 製作的 32×32×32 空島靜態網頁遊戲。

## 指令說明

- 執行單元測試：
  ```bash
  npm test
  ```
- 打包靜態網頁腳本（產生 `dist/bundle.js`）：
  ```bash
  npm run build
  ```

## 如何遊玩

1. 直接在檔案總管雙擊 `index.html` 用瀏覽器開啟（無需啟動伺服器）。
2. 點擊畫面中央鎖定滑鼠游標，進入第一人稱視角。
3. 操作方式：
   - **移動滑鼠**：自由旋轉第一人稱視角
   - **W / A / S / D**：前後左右水平移動
   - **Space（空白鍵）**：向上跳躍
   - **Esc**：解除滑鼠鎖定
   - **按住滑鼠左鍵**：挖準星對著的方塊（4 格內），泥土、沙子不到 1 秒，石頭約 2 秒；放開或移開就重來
   - **走到掉落的小方塊旁（3 格內）**：自動撿起來，快捷欄那一格數字 +1
   - **數字鍵 1～9 或滾輪**：選快捷欄的格子
   - **滑鼠右鍵**：把選中那一格的方塊放出去，數字 −1
   - 沙子下面沒有方塊會掉下來；沙子埋住頭部會扣血（左下角 HP，預設 20）

## 專案結構

- `src/logic/`：遊戲邏輯（世界、玩家、挖掘、掉落物、背包、沙子、血量），不依賴 three.js，可在 Node 測試
- `src/render/`、`src/main.js`：three.js 畫面與輸入
- `tests/`：Vitest 測試
- `dist/bundle.js`：打包好的成品，已放進 repo，所以雙擊 `index.html` 就能玩；改完程式後請重新 `npm run build`
- 先 `npm install` 再跑 `npm test` 或 `npm run build`
